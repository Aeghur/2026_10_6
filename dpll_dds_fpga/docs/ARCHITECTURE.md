# DPLL/DDS架构与定点约定

## 数据流

输入ADC码先减去实测中心码2104。带迟滞的正向过零检测器累计8个周期，
通过36周期串行除法器计算：

```text
phase_increment = 2^32 × 8 / period_sum
```

该结果负责1～100 kHz粗捕获。捕获阶段，NCO在正向过零点硬对齐；进入锁定后，
由I/Q鉴相和PI环路连续微调，不再进行硬相位复位。

NCO相位为32 bit无符号回绕数：

```text
0x00000000 =   0°
0x40000000 =  90°
0x80000000 = 180°
0xc0000000 = 270°
```

正弦ROM为1024点Q1.15。载波正弦、余弦分别由当前地址及加90°后的地址读取。
输入与正交载波相乘后使用一阶IIR低通。现在提供三档环路配置：

```text
y[n] = y[n-1] + (x[n] - y[n-1]) / 2^LPF_SHIFT
```

| 配置 | LPF_SHIFT | I/Q更新 | PI更新间隔 | 25 MSPS近似鉴相低通截止频率 |
|---|---:|---:|---:|---:|
| legacy | 14 | 每4样本 | 1024 | 61 Hz |
| balanced（默认） | 14 | 每样本 | 1024 | 243 Hz |
| fast | 14 | 每样本 | 256 | 243 Hz |

`legacy`保持原来的有效I/Q带宽，`balanced`加快I/Q建立，`fast`再把PI更新率提高
4倍，仅用于跳频和重捕获试验。三个模式使用相同的固定移位运算，避免在资源接近
满载的EP4CE6中推断宽桶形移位器。三档配置使用相同的AD9226固定流水线补偿，
均不包含上板实测得到的分频段相位补偿表。

对于输入`sin(phi_in)`，混频结果满足：

```text
I = A/2 × sin(phi_in - phi_nco)
Q = A/2 × cos(phi_in - phi_nco)
phase_error = atan2(I, Q)
```

`cordic_atan2.v`使用Q23角度，`pi = 2^23`，可区分正负误差和0/180°。
控制器每1024个有效相位样本更新一次PI环路，并限制频率字和积分器，防止失锁时
数值溢出。

扩展诊断状态可读取低通后的I/Q、模长、PI积分器、当前配置及实际移位参数。
内部`phase_error`接近零只表示NCO锁定到ADC数字样本，不等同于模拟输入和DAC
输出已经同相。

## 输出相位定义

PC和MSPM0继续使用“输出滞后输入”的正角度定义：

```text
phase_out = phase_nco
          - phase_lag
          + phase_calibration
          + digital_pipeline_advance
```

AD9226数据相对模拟采样点固定延迟7个采样周期，DDS映射再消耗2个采样周期，
因此RTL按当前`phase_increment`自动前移9拍：

```text
digital_pipeline_advance = 9 × phase_increment
```

在25 MSPS下，AD9226的7拍为280 ns；该补偿会随锁定频率自动换算为相位，
而不是只在某个频点有效。`phase_calibration`继续用于抵消板级极性和剩余的
亚采样周期DAC/模拟链路群延迟，仍需用示波器扫频复核。

## DAC映射

```text
dac_code = 8279 + amplitude_code × sin(phase)
```

正弦为Q1.15。幅度上限限制为8104码，所有结果最终饱和到0～16383。
默认幅度2143码，对应修复后DAC约0.492 Vpp。
顶层在`locked=0`时把幅度强制为0，使无输入和重新捕获期间的DAC保持在
零电压码8279，避免输出错误频率的正弦。

## 锁定标志

- 信号模长低于阈值时清除锁定并冻结有效输出判断。
- 连续32次环路更新处于±15°以内后置位`locked`。
- 连续8次超过±60°后清除`locked`。
- 粗测频与当前频率相差超过约3.1%时重新捕获。

锁定阈值是第一版安全初值，上板后应结合ADC幅度、噪声和跳频速度调整。
