# DPLL/DDS架构与定点约定

## 数据流

输入ADC码先减去实测中心码2104。带迟滞的正向过零检测器累计8个周期，
通过36周期串行除法器计算：

```text
phase_increment = 2^32 × 8 / period_sum
```

该结果负责1～100 kHz粗捕获。捕获阶段，NCO在正向过零点硬对齐；进入锁定后，
由I/Q鉴相和PI环路连续微调，不再进行硬相位复位。

NCO相位为32 bit无符号回绕数：

```text
0x00000000 =   0°
0x40000000 =  90°
0x80000000 = 180°
0xc0000000 = 270°
```

正弦ROM为1024点Q1.15。载波正弦、余弦分别由当前地址及加90°后的地址读取。
输入与正交载波相乘后使用一阶IIR低通：

```text
y[n] = y[n-1] + (x[n] - y[n-1]) / 2^16
```

对于输入`sin(phi_in)`，混频结果满足：

```text
I = A/2 × sin(phi_in - phi_nco)
Q = A/2 × cos(phi_in - phi_nco)
phase_error = atan2(I, Q)
```

`cordic_atan2.v`使用Q23角度，`pi = 2^23`，可区分正负误差和0/180°。
控制器每1024个有效相位样本更新一次PI环路，并限制频率字和积分器，防止失锁时
数值溢出。

## 输出相位定义

PC和MSPM0继续使用“输出滞后输入”的正角度定义：

```text
phase_out = phase_nco
          - phase_lag
          + phase_calibration
          + digital_pipeline_advance
```

其中`phase_calibration`由上板扫频得到，用于补偿ADC、DAC和模拟链路延迟。
RTL已经预补偿DDS内部两级流水线，但该值仍需用示波器复核。

## DAC映射

```text
dac_code = 8279 + amplitude_code × sin(phase)
```

正弦为Q1.15。幅度上限限制为8104码，所有结果最终饱和到0～16383。
默认幅度2143码，对应修复后DAC约0.492 Vpp。
顶层在`locked=0`时把幅度强制为0，使无输入和重新捕获期间的DAC保持在
零电压码8279，避免输出错误频率的正弦。

## 锁定标志

- 信号模长低于阈值时清除锁定并冻结有效输出判断。
- 连续32次环路更新处于±15°以内后置位`locked`。
- 连续8次超过±60°后清除`locked`。
- 粗测频与当前频率相差超过约3.1%时重新捕获。

锁定阈值是第一版安全初值，上板后应结合ADC幅度、噪声和跳频速度调整。
