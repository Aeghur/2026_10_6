# 丢2帧、取第3帧实验

入口：

```bash
.venv/bin/python experiments/gated_model/two_flush_two_stage.py --hardware --serve
```

依赖加载完出现 READY 后，输入 `run` 测量，输入 `quit` 退出。不加 `--serve` 为单次冷启动测量。保留丢1帧实验及原快速策略供对照。

每次采集丢弃2张，取第3张；启动仍预热8帧，曝光8 ms，其他模型、标定、候选筛选及确认阈值不变。报告明确记录 discarded_frames_per_capture=2 和 selected_frame_number=3。

2026-10-31同一输入连续三轮实测：

| 轮次 | 收到指令后的完整测量耗时 | 初测 | 精测 | 33.3 kHz三张评分 |
|---|---:|---:|---:|---|
| 1 | 4.537 s | 33.4 kHz | 33.3 kHz | 0.081、0.102、0.105 |
| 2 | 4.255 s | 33.3 kHz | 33.3 kHz | 0.059、0.103、0.108 |
| 3 | 4.159 s | 33.4 kHz | 33.3 kHz | 0.099、0.090、0.089 |

首次依赖导入7.43秒，未计入表中的常驻指令延迟。三轮共30张图，均通过原精测判据；当前输出保持33.3 kHz正弦。真实频率未作为输入，仅说明在当前信号上重复一致，尚不代表不同频段均有相同表现。

上一丢1帧实验三轮耗时3.43～3.76秒，仅一轮通过；原丢4帧策略对照导入后6.05秒通过。丢2帧在这组测试中取得更好的速度和稳定性折中。
