# 初测＋正弦精测

运行：

```bash
cd /home/radxa/vision_sorter
.venv/bin/python experiments/gated_model/two_stage.py --hardware
```

第一阶段沿用现有门控模型实拍，取三张模型输出的中位数为初测中心。
第二阶段输出五个正弦频率：中心−200、−100、0、+100、+200Hz，各拍3张，曝光8ms。
每个点比较单帧图形是否仍可解释为一条椭圆或直线，以及白色填充率。
不要求图形静止，不把帧间相位变化快慢加入得分。
频偏100Hz时在当前曝光/显示积分下容易产生多轨迹叠加；这是需要实测检验的判据，而不是通用的固定保证。

每张得分=自由相位椭圆/直线方程的归一化RMS残差＋0.5×白色填充率。
三张取中位数。最好得分需<0.18，且次好/最好≥1.8，才输出候选；否则明确返回不确定。
门限为实验参数，不是标定过的概率置信度。

成功后保持最终所选正弦，供观察相位变化或后续测相；没有明确胜者或异常时恢复100Hz门控、100μs下降段。
扫描区间只按用户要求覆盖±200Hz；若真值不在此区间，不自动扩大。
当前仅测频，不执行相位锁定。

可用`--coarse-summary /absolute/path/summary.json`显式复用已保存初测，但必须保证输入信号未改变。
默认总是重新初测，避免误用上一轮信号。

首次实测初测41.2kHz，精测正确区分41.3kHz：该点中位填充率约8.8%，其余四点约99%。
结果保存于artifacts/diagnostics/two_stage_20261031_094841/。

## 10秒内测量实验版

`fast_two_stage.py` 是独立实验入口，原 `two_stage.py` 保留。单次运行：

```bash
.venv/bin/python experiments/gated_model/fast_two_stage.py --hardware
```

常驻方式先加载依赖，再输入 `run` 执行一次全新的测量，输入 `quit` 退出：

```bash
.venv/bin/python experiments/gated_model/fast_two_stage.py --hardware --serve
```

快速版只打开一次相机。初测依次尝试50、250、2000 μs，找到有效行比例≥90%、局部拟合误差<0.02的图后立即用原模型推理；不复用上一轮频率。精测仍扫描五个候选，每个先拍一张，再对评分最好的两个候选分别补拍两张，以各三张的中位数使用原判据。保留相机清除四张旧帧的操作，取消额外0.4/0.5秒等待。曝光仍为8 ms。

代价：初测的重复一致性检查减少，未入围的三个候选仅有一张图；不能宣称与完整流程具有相同鲁棒性。无法得到清晰初测或没有明确精测优胜者时不报告确定频率，恢复快降脉冲。低频需要更多探测窗口，不能保证所有信号都在10秒内完成。

2026-10-31同一输入实测：独立冷启动13.13秒，其中依赖导入7.00秒、导入后测量6.13秒；常驻收到 `run` 后连续两次测量6.01秒、6.00秒，结果均45.5 kHz。首次启动不计入常驻测量延迟，但必须单独说明，不能将6.01秒写成冷启动总耗时。每次都保存原图、矫正图、掩膜及计时报告。
