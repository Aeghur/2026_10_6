## 实际计算链路

校正384×384灰度图 + 每张图公开扫描时序
→ 128个固定行的横向质心
→ 对100 Hz档位拟合sin/cos/DC，选出粗候选
→ 多图共享相位并搜索9档相对时钟误差
→ 每候选5维特征
→ Ranker排序 → 候选频率。

这不是直接吃图片的CNN，也不是斜率模型。
网络主要在物理拟合评分上作学习修正；现有验证没有显示优于物理基线。

## 原采集计划

重复周期固定10000 μs，即100 Hz。

1. 粗测：active_us分别为50、250、2000，delay_us均为0，各拍一张。
2. 粗测图选择接近4个周期的扫描长度，候选池为50、100、200、500、1000、2000、4000 μs。
3. 精测：使用选中的同一个active_us，delay_us分别为0、1700、4300，各拍一张。
4. 最终联合推理只使用后三张精测图；前三张用于选窗口，不应全部混入联合拟合。

例如21 kHz的仿真选择200 μs（4.2周期），67.1 kHz选择50 μs（3.355周期）。
不同扫描命令应保持同一个10 ms超帧基准，且帧与超帧序号关联。
训练中相邻命令间隔120 ms，曝光/积分60 ms，相对时钟误差±5 ppm。

## 图像要求

- 准确384×384灰度位图，不是随意resize整张相机照片。
- 完整扫描低端在y=345，高端在y=38；有效提取行排除两端各6像素。
- x沿正弦电压变化，横向中心约191.5，仿真半幅125–151像素。
- 黑背景；应保留弱曲线，网格和界面不能主导逐行质心。
- 完整扫描端点必须独立标定，不能用未知正弦曲线的可见外包框代替。

当前校正图为960×640，用户随后确认更新后的硬件总幅度4Vpp，屏幕Y为500mV/格，因此按完整扫描640像素处理。
应围绕已知停留线与另一个端点，将这640像素映射至模型的y=38..345。
这不同于原先将整个8格画面塞入307像素高的标准画布。
实际下降方向与模型的时间方向必须核对；不能把翻转后的图与未翻转的时间映射混用。

## 独立推理入口

已生成一个真实可运行的仿真示例：

```bash
cd /home/radxa/vision_sorter
.venv/bin/python experiments/gated_model/infer.py \
  --observations artifacts/diagnostics/gated_model_inspection/67100/observations.json \
  --output artifacts/diagnostics/gated_model_inspection/67100/inference.json
```

实拍接入时准备同样格式的JSON；以下是结构示意，时序必须换成实际元数据：

```json
{
  "repeat_us": 10000,
  "exposure_ms": 60,
  "timing_epoch_verified": true,
  "endpoint_mapping": {"top_y": 38, "bottom_y": 345},
  "observations": [
    {"image": "fine0.png", "active_us": 200, "delay_us": 0, "frame_index": 36},
    {"image": "fine1.png", "active_us": 200, "delay_us": 1700, "frame_index": 48},
    {"image": "fine2.png", "active_us": 200, "delay_us": 4300, "frame_index": 60}
  ]
}
```

`frame_index`是连续硬件超帧编号，不能直接用图片序号或上位机收到图片的时间替代。
入口要求三张精测图；检查尺寸和有效行，输出Top5、物理基线、阶段耗时及条件匹配标志。
`rank_score`不是成功概率，`confirmed`始终为false；没有实拍校准的成功置信度。

## 当前实机接入差异

- 硬件现为100 Hz快降脉冲：长时间保持零端，瞬间上升，再线性下降；训练为线性上升、高端保持。
  图像方向可能通过端点映射适配，但跨图共享相位所需的有效段开始时刻必须匹配。
- 当前UART支持频率、相位、幅度和下降时长，但没有返回连续超帧编号及命令边界生效时刻。
  相位字段能否可靠代替delay_us、命令是否重置基准，尚未从硬件实现确认。
- 相机当前8ms，训练设置60ms积分；示波器显示积分也会影响叠加，不能简单把二者视为同一时长。
- 当前HSV阈值较高，点状线存在缺失；推理入口会拒绝有效行不足90%的输入。

因此目前已验证权重和离线推理可用，尚未声称该模型已完成实机测频接入。
下一步应先确认时序能力及端点归一化，再采集同一组实拍图同时对比物理基线与学习排序结果。
