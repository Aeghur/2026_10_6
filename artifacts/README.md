# Generated image artifacts

These directories contain generated captures and reports rather than source
code. Scripts create missing directories automatically.

- `captures/`: raw camera test frames and rectified camera checks
- `calibration/scope/`: scope graticule overlays, warped views and JSON reports
- `calibration/lens/`: checkerboard captures, detected previews and lens models
- `diagnostics/`: current trace masks and detailed axis diagnostics
- `results/`: final closed-loop images and `result.json`
- `legacy/`: outputs retained from the original virtual-scope workflow
